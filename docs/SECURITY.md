# Security model

A forged leader cannot safely flip a blocking causal criterion to support because validators independently fetch the frozen sources and independently re-run the bounded classification. Model output that changes candidate/criterion shape or invents statuses fails closed.

Fetched web evidence is untrusted data. The prompt explicitly forbids following instructions embedded in sources, labels, outcome text, candidate statements or criterion text. Independent validation and deterministic result derivation remain primary defenses.

Source substitution is prevented by sealing exact URLs into the case definition. HTTPS and basic public-host checks provide defense in depth against obvious local/private targets.

Atomic all-candidate resolution avoids evidence-time drift between competing hypotheses. A frozen minimum source-availability rule prevents false certainty during source outages.

The protocol explicitly allows MULTIPLE_SUFFICIENT_CAUSES instead of forcing false uniqueness. The sample consumer pins definition hash and protects action replay.

CausalGate proves only that consensus-backed evidence classifications satisfy the standard actually frozen; it does not certify that the chosen causal standard is scientifically, legally, medically or operationally sufficient for a domain.
